## 本次完成的代码

- Definition staging 借用既有 slot，记录成同一 pending publication 的 prerequisite。
- A5 resident scheduler 的 host vector 移入同一记录；device allocation 仍由原 scheduler owner 管理，legacy 分支不新增 scheduler 上传。
- Definition → scheduler → compact image 顺序同步发布；任一 copy 失败后消耗整条记录，停止后续写入，原 failed-prepare 路径清理 device 资源。
- 准备失败清除部分记录；拒绝覆盖尚未发布的 run；tensor staging、host get/set 和每次重新编排保留。
- trace 关闭核对本次 HostApi owner，避免旧 run 的 release 关闭新 run 的 trace。GraphUpload / ArenaH2d 记录真实成功复制及字节数。
- TMR/HBG 公共 descriptor 在 prepare 中形成独立值快照，再同步 publish；失败撤销本次 launch pointer，slot allocation 保留。

不改变 Pipeline A admission/fence/drain，不新增公开 API，不实现异步、capture/replay 或 PreparedCall reuse。Descriptor 快照新增一次 descriptor 大小的 host allocation 和 CPU copy；没有声称性能提升。

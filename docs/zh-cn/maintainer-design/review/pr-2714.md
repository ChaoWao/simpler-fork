## 1. 背景与目标

普通 Host Tensor 默认 H2D，设备获得独立副本；HOST/NONE 使用原生 Host 地址。Engram 完整表需要保留在 Host DDR，由设备按索引访问，避免整表 Device 副本和搬运。

本 PR 的范围是同进程、owning direct L2、单 A5、TMR/HBG 的本地同步 MTE 访问，支持 IN/OUT/INOUT。L3 共享整表属于 #2731/#2893；rank-local Host shard 的跨 rank 通信属于 #2922。异步 overlap 和应用集成继续由 #2657 组织，不能因本 PR 合入便视为完成。

```python
buffer = worker.create_buffer(nbytes)
tensor = buffer.tensor(shape, dtype)
args.add_tensor(tensor, TensorArgType.INPUT, transfer=TensorTransfer.MAP)
worker.submit(entry, args).wait()
worker.release_buffer(buffer)
```

原生 Host Buffer/Tensor 不改变身份。同一 Tensor 在另一有序调用可选 H2D；MAP 访问同一 backing，不提供快照、同步或自动 gather。

## 2. 机制与取舍

TaskArgs 记录每个参数的 transfer；提交准备检查 ownership、context、loaded-runtime capability、grant、范围及可写 H2D/MAP 别名冲突。ImportRegistry 按参数独立生成 binding，将 MAP 解析为内部 DEVICE/NONE，保持 canonical identity 和 Tensor 几何。旧公开 map_view/unmap_view 已被取代，不新增 Tensor 类型或公共引用计数器。

HostMappingRegistry 隶属于 Worker 的 ImportRegistry，按 whole Buffer 缓存 ACL registration，按 run_id 保留调用使用。Worker registry lock 保护首次发布，Buffer owner lock 先于 mapping lock，准备与释放共享边界。A5 backend 执行 ACL register/get-pointer/unregister；映射不触发通信域、peer 或 URMA workspace。

正常完成释放使用引用，健康注册留到 Buffer release。busy 拒绝不关闭接纳；实际 unregister 前关闭接纳，失败保留 backing/context 供重试；未知完成继续保留资源。HostSharedMemory 使用 carrier 与 mmap export finalizer 保留 NumPy 派生数组；普通 Buffer 和通信域共享该机制但分别拥有 allocation/unlink。

本轮 framework 修复在已证明可退休后、native retire 和 terminal publication 前释放 Host uses。Device-source 成功释放后已从原字典移除；Host release 按 run_id 幂等，因此后续重试不会重复 Device decrement。Device-source 部分释放后抛错仍进入原来的 unknown guard，Host 引用不提前释放。`seal_host_mappings(..., seal=False)` 保留主线通信域的非封闭检查语义。

收益是避免整表 HBM 副本和稳态全表搬运，保持存储身份、访问策略与传输资源的职责边界。成本是提交验证、锁、注册缓存和完整的引用退休；需要按真实用途维护这些状态。未测本轮吞吐或提交开销，不宣称速度提升比例。
